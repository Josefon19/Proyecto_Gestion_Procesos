# Calculadora Financiera CI/CD

![CI](https://github.com/Josefon19/Proyecto_Gestion_Procesos/actions/workflows/ci.yml/badge.svg)

**Descripción del proyecto:**
Este proyecto consiste en una calculadora financiera desarrollada en JavaScript con módulos para el cálculo de IVA, aplicación de descuentos y cálculo de intereses. Además, implementa un pipeline de Integración Continua (CI) mediante GitHub Actions que automatiza el análisis estático de código con ESLint, la ejecución de pruebas unitarias y la publicación del reporte de cobertura con Vitest en GitHub Pages.

* **URL del Repositorio:** https://github.com/Josefon19/Proyecto_Gestion_Procesos
* **Reporte de Cobertura:** https://Josefon19.github.io/Proyecto_Gestion_Procesos/
